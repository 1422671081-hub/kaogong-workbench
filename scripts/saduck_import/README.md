# SaDuck 版 PDF 录题流程（2026-09-19 实战验证，130/130 题）

适用：桌面 题库/ SaDuck 版历年卷（页眉「历年试卷 | SaDuck」，无文字层、矢量绘制、答案红色标注）。

## 五步
1. cache_lines.py  —— 整本 OCR（PyMuPDF get_textpage_ocr 300dpi + tessdata），缓存每行坐标/文本/是否红色
2. parse_zf5.py    —— 核心：视觉行合并(y0±6) -> 题号(左缩进x0<46.5+序号序列) -> 选项族(连续4行同缩进,
   不认字母只认位置) -> 答案靠红色矢量路径(get_drawings fill~(1,0,0))定位。缺行自动占位并写 repair 清单
3. 看图修补 —— 对 repair 清单和缺号题，get_pixmap(clip=...) 渲染局部放大图，人工读出文本回填
   （INJECT 列表回填整行丢失的题号行；patch_zf.py 回填选项文本）
4. convert_zf.py  —— 转工作台格式(pid/paper/part/stem/options/answer/explain)，板块按题号分界，
   外加 OCR 高频错字安全替换表(完法->宪法/友展->发展等)
5. local_store.py add-q --json ... && local_store.py build

## 踩过的坑
- 提高 DPI 无效：矢量绘制文字，OCR 天生吃力，靠颜色+坐标绕开
- 选项字母识别不可靠（C->5/Cc/<C），位置才是权威 -> 答案根本不依赖 OCR 字母
- 页眉「历年试卷|SaDuck」会被拆成两个碎片，噪声过滤必须在视觉行合并之后做
- 题干与选项间的正常空行(约34-38pt)不是缺行；缺行间距约48-55pt，阈值用 1.9x 行距
- 图形推理/表格选项：选项文字只有字母或表格碎片，统一写「(图形)」/重构表格文本
- 答案分布校验：2022行政执法卷 A32/B33/C32/D33，分布异常说明切分出错

## 裁图坐标必须用行缓存，不能目测（2026-09-20 教训）
- recrop_imgs.py：用 OCR 行缓存的真实 y 坐标 + 锚点行定位裁切边界（标题行/题号行/解析首行）
- 目测 110dpi 缩略图的坐标系统性偏移 30-80pt，导致 121 材料图带上一题解析、底部图表被切，
  111 表格少 4 行+合计行——用户做题时发现
- 注意 OCR 锚点变体：受理→这理、亿元→亿元网、表格行大量丢失（116 表只认出 9 月一行碎片）
- 86b 终点=「第一步」解析首行；116b 起点=页眉下第一条内容行（件 标签 y31.7）

## 批量模式（2026-09-20，12 套 2023-2026 国考卷全量录入验证）
- batch_lib.py 卷配置 PAPERS（含各年执法卷文件名后缀差异：2023/2026 无「卷」字）
- 流程：run_batch.py cache(OCR~2min/卷) -> run_batch.py(解析) -> batch_repair.py(条带OCR自动修补)
  -> fallback_and_render.py(缺选项题裁选项区图挂imgs兜底; 渲染人工修补条带) -> 人工读图 -> finalize_batch.py
  -> batch_imgs.py(图形推理整题图/资料分析材料图/图表题干图) -> import_batch.py(add-q+build)
- 关键事实：部分卷面本身跳号（2024地市缺101-110、2023副省缺33），不是OCR丢题——先渲染确认再修补
- 资料分析最后一题几乎都是「折线图/饼图选项」题，OCR必失败 -> 整题图+红标人工读答案
- 12套结果：1569题、0无答案、0选项缺、122+31配图；人工修补仅16图片题+2文字题

## 图片验证轮（2026-09-20 凌晨）
- final_fix2.py / final_patch2.py：材料图修复落地
- 验证发现的四个坑：
  1) 组归属判定 s0<=id<f+5 会把后面组累加挂到前面题上 -> 必须 f<=id<f+5，且重跑前先 pop imgs
  2) 材料锚点「故正确答案|故本题选|综上」中的「综上」会命中组合题解析中间 -> 去掉「综上」
  3) 搜索窗 80 行不够（图表选项题解析长），放大到 250 行
  4) 锚词 OCR 变体（敌正确答案）+ 材料文字被并进上题 explain -> 迭代前移会被材料数字行误触发越裁越少；
     终极方案 = explain 子串法（上题 explain 去空格后与缓存行匹配）；仍失败的少数组渲染条带人工定界
- 跨组共用材料：组间复用前一组的 mat（2026地市121-125复用116、2026/2023副省131-135复用126）
- 终验标准：引用图全存在、无空白/过小/过矮、无孤儿、无(待校)、无无答案、资料分析 20/20 带材料图

## 文字层版式解析器（2026-09-20，「常规版」PDF 专用）
- p2018_parse.py：Desktop\行测真题pdf\ 约300份「-全部题目-常规」版 PDF 全有文字层（粉笔排版），
  走纯文本解析，不需要 OCR
- 要点：get_text(dict) 后必须按 y 合并视觉行（题号「1.」与题干、选项「A.」与内容是独立 line，
  合并后为「1.题干」**无空格**，QNO 用 \d+\s*[.、．]?\s* 宽匹配）；
  解析区切分锚=「【答案】X」，题号常与【答案】同行（「1.【答案】 D」），两个分支都要提取答案
- 已知限制：数学公式/部分选项是嵌入位图 -> 解析缺推导数字、个别选项提取不到（挂整题图兜底）
- 2018副省首跑：135/135、答案分布 A34/B32/C32/D37、材料图4组、整题图兜底10题
