# 考公工作台 · 使用教程

> 面向两种使用者：**把 PDF 丢给 AI 助手的人**（推荐，全程不用敲命令）和**想自己跑脚本的人**。
> 先读这篇，再深的细节去翻 `SKILL.md`。

---

## 一、最快上手：把 PDF 丢给 AI

你只需要一句话：

> 「把这套卷子录进题库」+ 附件 PDF

AI 会自动完成：检测文字层 → 提取题目/选项/答案/解析 → 裁切图表 → 入库 → 重新生成刷题页。
你唯一要做的是最后**双击打开 `考公工作台.html`**。

目前验证过、可以全自动处理的两种 PDF：

| 版式 | 特征 | 处理方式 |
|---|---|---|
| **粉笔「常规版」** | 文件名带「-全部题目-常规」，有文字层 | 纯文本解析，约 1 分钟/套 |
| **SaDuck 版** | 页眉带「历年试卷 \| SaDuck」，无文字层、答案红色标注 | OCR + 红色定位，约 5-8 分钟/套 |

> ⚠️ 防复制字体的 PDF（`pdftotext` 出乱码）也可以处理，但流程更慢，
> 丢给 AI 时说一句「这个 PDF 文字层可能有问题」，它会先探测再选路。

## 二、刷题页功能详解

生成/打开 `考公工作台.html` 后：

### 1. 选试卷（顶部一排蓝色按钮）

- **📚 全部试卷**：显示题库里所有题
- **📄 国考各卷**：平铺排列，点哪套刷哪套（再点一次取消筛选）
- **🗺 省考**：省考试卷的下钻入口
  - 点「省考」→ 弹出**省份列表**（安徽、北京、浙江……有几个省显示几个）
  - 点省份 → 弹出该省的**具体试卷**
  - 点试卷 → 开始刷；顶部随时可「‹ 返回」上一层

> 省考试卷按「{年份}{省名}省考{类别}」命名（如「2023安徽省考」），
> 录入时遵守这个命名，省列表会自动归组，不需要改页面代码。

### 2. 选模块（第二排粉色按钮）

五大模块：常识判断 / 言语理解 / 数量关系 / 判断推理 / 资料分析。

- **言语理解**▸：逻辑填空 / 片段阅读 / 篇章阅读 / 语句表达
- **判断推理**▸：图形推理 / 定义判断 / 类比推理 / 逻辑判断
- **资料分析**▸：基期量计算 / 现期比重计算 / 增长量比较 / 综合分析 等 14 个考点
- 图形推理和资料分析的图表**直接内嵌在题目里**，可左右滑动、点击放大

### 3. 刷题与错题

- 答错自动进错题本（同一题错多次只记一次）
- **错题重做时不显示答案**，必须重新作答
- 首页的「错题重做」按钮随机抽错题

### 4. 艾宾浩斯复习

答错后按 **1 / 2 / 4 / 7 / 15 / 30 天**安排 6 轮复习：
- 首页「🔁 今日复习 (N)」显示今天到期的数量
- 复习答对 → 推进一轮；答错 → 打回第 1 轮
- 走完 6 轮 = 毕业

### 5. 打卡与统计

刷完点打卡，自动记录当日各模块题量/正确率/用时，统计页有图表。

### 6. 数据安全

刷题记录存在**浏览器 localStorage** 里，换电脑/换浏览器不互通。
想备份：直接复制整个 `kaogong-data/` 目录（本地模式）。

## 三、命令行用法（本地模式）

```bash
# 初始化数据目录（首次）
python3 scripts/local_store.py init --dir ./kaogong-data

# 录题 / 更新（pid 相同会覆盖）
python3 scripts/local_store.py add-q --dir ./kaogong-data --json 新卷子.json

# 报错题 / 查今日复习 / 报复习结果
python3 scripts/local_store.py wrong  --dir ./kaogong-data --pid "2023安徽省考-45"
python3 scripts/local_store.py due    --dir ./kaogong-data
python3 scripts/local_store.py review --dir ./kaogong-data --pid "..." --right

# 打卡 / 统计
python3 scripts/local_store.py checkin --dir ./kaogong-data --module 言语理解 --done 10 --correct 8 --minutes 15
python3 scripts/local_store.py stats   --dir ./kaogong-data

# 生成/更新刷题页（改完题库必跑）
python3 scripts/local_store.py build --dir ./kaogong-data
```

## 四、录题的三条路线（给 AI / 进阶用户）

| 路线 | 适用 PDF | 入口 | 速度 |
|---|---|---|---|
| ① 文字层解析 | 粉笔「常规版」等有文字层的 PDF | `scripts/saduck_import/text_paper_parse.py` | ~1 分钟/套 |
| ② OCR + 红色定位 | SaDuck 版（无文字层） | `scripts/saduck_import/` 全套批量脚本 | ~5-8 分钟/套 |
| ③ 手工誊录 | 扫描件/拍照 | 把题目文字整理成 JSON 后 add-q | 看手速 |

路线 ①② 的详细流程、踩坑记录见 `scripts/saduck_import/README.md`。

**单套卷子（路线①）示例**：

```bash
python3 scripts/saduck_import/text_paper_parse.py \
    "试卷.pdf" "2023安徽省考" "输出.json" 110
```

四个参数依次是：PDF 路径、试卷名（含省名的按省考命名规范）、输出 JSON、总题数。
跑完用 `add-q` 入库即可。

**批量（路线②）示例**：

```bash
# 1. OCR 缓存（每套约 2 分钟，可中断续跑）
python3 scripts/saduck_import/run_batch.py cache
# 2. 解析 + 修补 + 配图 + 入库（详见 saduck_import/README.md）
```

## 五、省考模块说明

- 录入省考试卷时，`paper` 字段按 **「{年份}{省名}省考{类别}」** 命名：
  - `2023安徽省考`、`2024浙江省考A类`、`2018上海市考B类`
- 刷题页的「🗺 省考」按钮会按卷名里的省名**自动分组**，出现「省 → 试卷」两级下钻
- 卷名里不含省名的试卷归入默认平铺区（如国考各卷）

## 六、常见问题

**Q：图片能发给别人看吗？**
能。图片全部 base64 内嵌进 HTML，单个文件发微信/拷 U 盘都行。

**Q：刷题页文件越来越大？**
正常。每套卷的图表都内嵌在里面，40+ MB 属正常范围，双击打开稍慢几秒。

**Q：全国真题那么多，一个文件放不下怎么办？**
 支持  参数按卷生成独立文件。批量分省生成见
（国考一份 + 每省一份，如 、
），每份 10~70 MB，刷哪省开哪省。

**Q：省考卷怎么命名？**
「{年份}{省名}省考{类别}」，如 、。刷题页按卷名里的
省名自动归入「🗺 省考」下钻列表。

**Q：解析里有乱码/错字？**
OCR 路线录的卷子错字率约 5%（高频错字已自动替换）。做题时发现错字/错答案，
把「卷名-题号」发给 AI 单独修正即可。

**Q：图形推理的选项是「(见图)」？**
图形题的选项本身就是图，整题已截图嵌在题目上方，看图作答即可。

**Q：想删掉某套卷子重录？**
删掉 `questions.json` 里对应 `paper` 的题目后重新 `add-q` + `build`。
